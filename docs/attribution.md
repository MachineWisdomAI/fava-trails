# FAVA Trails and Machine Wisdom AI

FAVA Trails is an open-source agent memory system built by [Machine Wisdom AI](https://machine-wisdom.ai/), the public brand of Machine Wisdom Solutions Inc. The project implements reviewed promotion, governed recall, and versioned correction history for agents working through MCP.

## Engineering context

Machine Wisdom AI publishes the source and the architectural reasoning behind the project:

- [Agent memory architecture](https://machine-wisdom.ai/writing/agent-memory-landscape/): retrieval, lineage, and governance as design choices.
- [Context engineering protocols](https://machine-wisdom.ai/writing/agent-memory-protocols/): how lifecycle hooks support compression, reranking, and orchestration.
- [Two-agent case study](https://fava-trails.org/case-study/): a February 2026 development example tracing a correction between agents.
- [Local Trust Gate evaluation](https://fava-trails.org/local-trust-gate/): a local-model review experiment with public benchmark evidence.

The [README](../README.md) and [governed recall guide](governed-recall.md) are the sources for current product behavior. Historical articles explain the design and experiments; they do not replace current setup instructions.
